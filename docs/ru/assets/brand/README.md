# Фирменные материалы Collaborative

Публичное название — Collaborative. Символ объединяет четыре петли вокруг
квадратного просвета; верхняя правая петля выделена мятным цветом.

<a id="files"></a>

## Файлы

- [Символ](../../../assets/brand/collaborative-symbol.svg).
- [Логотип для светлого фона](../../../assets/brand/collaborative-logo-light.svg).
- [Логотип для тёмного фона](../../../assets/brand/collaborative-logo-dark.svg).
- [Обложка репозитория 1280 × 640](../../../assets/brand/collaborative-social.png).

SVG — редактируемые исходники с векторными контурами, включая буквы. В них нет
растровых вставок, внешних шрифтов и скриптов. Используется Geist под
[SIL OFL 1.1](https://github.com/Asmblyr/Collaborative/blob/main/apps/ui/src/app/fonts/OFL.txt).

Сохраняйте геометрию, пропорции и свободное пространство вокруг символа.
Выбирайте версию для нужного фона. Основные цвета: графит #1B2930, мятный #88BFAA,
тёплый белый #F5F3EE.

README выбирает логотип по светлой/тёмной теме читателя. Social preview GitHub
задаётся отдельно в настройках: добавление PNG в Git не выбирает его автоматически.

Скриншоты продукта размещаются в docs/assets/screenshots и используют вымышленные
данные. Не публикуйте персональные данные, секреты и приватные адреса инфраструктуры.
