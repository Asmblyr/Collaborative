# Подписи записей и редактор связей — 29 сентября 2026

## Изменения

- Настройка displayField для коллекции; подписи в карточках, поиске, фильтрах и выборе связей.
- GET/PATCH/POST для именованных O2M/M2M-связей: страницы, привязка, отвязка, создание.
- Транзакционное сохранение данных и истории; права проверяются на фактические изменения дочерней или промежуточной коллекции.
- Единый поиск записей в popover на shadcn, с пагинацией и загрузкой подписей выбранных ключей.
- Вложенные редакторы держат родительскую форму смонтированной; уникальные ID полей предотвращают конфликт фокуса.
- Боковое меню: компактная общая навигация, разделитель, счётчики папок, акцент на выбранной коллекции.

## Проверено

- 19 тестов: новые интеграционные сценарии редактора, регрессии создания связей и поиска, UI-модель фильтров, подписи и ограничения полей.
- Core/UI: typecheck и lint.
- Миграция 20260929010000 применена к существующей локальной БД. Добавляет nullable-метаданные, не изменяет пользовательские записи. Откат запрещён при настроенных подписях.
- Сравнение изменений с резервной копией до этапа; новые модули разделены по задачам. Изменённый CollectionsTable остаётся менее 350 строк; добавлена только передача действия отображения.
- Браузер: загрузка страницы и открытие карточки с новой подписью. Полный сценарий выбора/создания/отвязки через UI требует дополнительного ручного прогона.

## Границы

- O2M/M2M сохраняются сразу; M2O-выбор сохраняется с основной карточкой.
- Создание из M2O-селектора сразу сохраняет отдельную запись, даже если основную карточку потом закрыли.
- Промежуточная коллекция с дополнительными обязательными полями заполняется обычным редактором. При их отсутствии в запросе связанное создание целиком откатывается.
- Сохранённая связь не удаляет связанную запись при отвязке; O2M с required или NOT NULL не очищается.
- Повторная привязка со стороны одного родителя сериализуется. Одновременная вставка одной пары с противоположных сторон может встретить ограничение уникальности и вернуть конфликт.
