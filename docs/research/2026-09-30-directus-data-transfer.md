# Локальный перенос данных из Directus

Дата исходной проверки: **2026-09-30**. Это исторический отчёт о разовом переносе
в локальную PostgreSQL Asmblyr. Источник был прочитан без изменений.
Данные, внутренние количества и идентификаторы исходной установки не публикуются.
Полный исходный отчёт и снимки остаются локально вне Git.

## Технический результат

Перенос сохранял исходные ID, NULL, даты, JSON, точные денежные суммы, связи,
первичные ключи и уникальность. Последовательности serial переведены на максимальные
перенесённые ID. Исходные физические типы и presentation metadata проверялись
отдельно: метаданные Directus не копировались механически.

Проверялись количество строк, контрольные суммы всех физических полей, целостность
FK, отображение в каталоге Core и чтение через item service. Согласованное
преобразование системных дат и автора выполнялось отдельной транзакцией после
пробного запуска с rollback. Неизвестные исторические даты оставлены NULL.

## Воспроизводимость

Снимок должен находиться в локальной `.local-data/directus-transfer/`, исключённой
из Git и Docker-контекста. Инструмент рассчитан на этот конкретный формат снимка,
не является общим импортом/экспортом или синхронизацией и допускает только локальную БД.

Из `apps/core`:

```powershell
pnpm exec tsx scripts/directus-transfer/cli.ts --check
pnpm exec tsx scripts/directus-transfer/cli.ts --import
pnpm exec tsx scripts/directus-transfer/cli.ts --verify

$env:DIRECTUS_TRANSFER_AUTHOR_EMAIL = 'author@example.test'
pnpm exec tsx scripts/directus-transfer/normalize-audit-cli.ts --verify
```

`--check` выполняет полный rollback. `--import` прекращается при наличии целевых
коллекций. Проверка исходного переноса закономерно сообщает о расхождении после
последующих изменений данных. Для уже нормализованного снимка используется
отдельный `normalize-audit-cli.ts --verify`; `--apply` не предназначен для повторного
запуска на уже обработанной БД.
