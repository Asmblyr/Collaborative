# Подготовка открытого репозитория

Проверка **03.10.2026** для `Asmblyr/Collaborative`, лицензия MIT.

## Состав публикации

Исходники, миграции, тесты, пустые шаблоны конфигурации и документация сохранены.
Из Git и Docker-контекста исключены реальные env-файлы, приватные ключи, локальные
данные, выгрузки, backup, логи, артефакты проверки и скриншоты локальных установок.
Генерируемые облачные `resources.json` и `bucket-policy.json` также остаются локальными.

Полный отчёт с внутренней схемой Directus заменён публичным техническим резюме.
В исторических документах убраны адреса закрытой установки и реальные облачные ID.
Оригиналы сохранены в игнорируемой `.local-data/publication-originals/`; генератор
документации не читает этот каталог. Ссылки на исключённые локальные изображения
заменены текстовыми пояснениями.

Инструмент нормализации переноса получает email автора через
`DIRECTUS_TRANSFER_AUTHOR_EMAIL`; без него прекращает работу до обращения к БД.
Облачный provisioning принимает folder, bucket, JWKS и kubeconfig параметрами.
Рабочие конфигурации, пароли и облачные ресурсы этой подготовкой не менялись.

## Проверки

Публикуемый набор экспортирован отдельно от локальных данных и проверен Gitleaks
8.30.1 с полным маскированием вывода: обнаруженных секретов нет. Дополнительно
проверены известные приватные адреса/ID и фактические правила Git ignore.
Проверки типов Core и инструмента переноса, lint изменённого инструмента,
PowerShell syntax и сборка документации прошли.

Один первоначальный commit GitHub содержит MIT-лицензию; локальная публикация
сохраняет его в качестве родителя. В новые commits используется GitHub noreply
email. История с локальными выгрузками не создаётся и не отправляется.

Эта проверка относится к данному набору файлов. Новые исходники могут содержать
вставленные вручную секреты даже при корректном `.gitignore`; перед следующими
публикациями нужно снова проверять содержимое добавленных файлов.
