# Аудит 3 октября 2026

## Область и метод

Проверены текущие маршруты Core, guards/services, BFF, auth/SSO/federation/OAuth, item projections и hooks, files, настройки и зависимости. Сопоставлены исходники и тесты; локально просмотрен раздел настроек. Это аудит данного checkout, без проверки production-инфраструктуры и без полноценного pentest.

## Подтверждённые защиты

- Auth tokens случайные, в БД hashes; refresh rotation/reuse revoke и disabled-user проверка.
- Политики коллекций/полей исполняются общим слоем данных; history/search/relations учитывают grants.
- Настройки имеют отдельные section grants с отзывом без нового login; machine token не получает settings через политику.
- SSO flow проверяет протокольные доказательства; одинаковый email не является основанием автоматического linking.
- GitLab assertion проверяет issuer/audience/signature/project/ref/time и защищён от повторного jti.
- Зарезервированная структура защищена; plugin installation/migrations имеют ownership и transaction checks.
- HTTP/MCP model handlers используют общую реализацию и caller data permissions.
- File read проверяет readable reference; preview ограничен CSP/nosniff.

## Открытые вопросы по приоритету

| Приоритет                     | Наблюдение и доказательство                                                                                | Следствие / следующий шаг                                                                            |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |

| Высокий для сторонних пакетов | `plugins/load.ts` и Kit: Node code загружается в Core                                                      | Capabilities не sandbox; до недоверенных пакетов нужна отдельная изоляция                            |
| Средний                       | `permissions/access.ts`: grants без row predicates                                                         | Нельзя обещать доступ «только к моим записям»; добавить единую модель условий позже                  |
| Средний                       | `auth/rate-limit.ts`, `login-rate-limit.ts`: локальные counters                                            | Несколько реплик не делят квоту; добавить ingress/shared limiter                                     |
| Средний                       | `files/routes.ts`: буфер загрузки до 25 MiB; DB и S3 отдельно                                              | Нужны concurrency/quotas, reconciliation, antivirus по требованиям                                   |
| Средний                       | `items/events-repository.ts`, assistant telemetry: нет общего автоматического retention                    | Рост БД; определить сроки, очистку/архив и контроль объёма                                           |

| Средний                       | BFF допускает отсутствие Origin; deployment headers вне этого аудита                                       | Проверить реальный ingress, HTTPS/cookies/forwarded headers; не считать только UI защитой API        |

## Проверки

Полный прогон: SDK **13**, Core **282**, UI **78** успешных тестов; ошибок **0**. Один live-тест LavinMQ пропущен: ему требуется отдельное окружение. В числе Core проверок — новые section grants, объединение политик, revocation, disabled users, machine denial и сохранение настроек делегированным пользователем.

Отдельный новый smoke-тест `http-access-surface.integration.test.ts` проверил **все 135 защищённых статических маршрутов** при включённом OAuth provider: без Bearer каждый вернул 401. Публичные credential/protocol endpoints проверяются профильными тестами. Этот smoke не заменяет проверку прав уже вошедшего пользователя и не охватывает все динамические plugin routes.

`pnpm typecheck`, `pnpm lint` и `pnpm build` — успешно. `pnpm audit --json` — 0 известных advisories на установленном lockfile. Это результат базы advisories на дату проверки, не оценка всего исходного кода.

`pnpm docs:check` и сборка VitePress прошли: 149 деклараций маршрутов, проверка ссылок включена. TypeDoc документирует публичные экспорты основной точки входа SDK/Kit; 14 предупреждений Kit относятся к упомянутым вспомогательным типам без отдельного публичного экспорта. Browser UI API описан также в руководствах Kit. Live облачные credentials/ACL, TLS/ingress, backup recovery, нагрузочные сценарии и полный браузерный регресс не проверены.

4. Для недоверенных расширений — sandbox; для внешних событий — outbox.
