# Asmblyr Collaborative

**Открытая платформа для работы с данными и совместного редактирования.**
Создавайте коллекции и связи в PostgreSQL, управляйте записями через админку,
настраивайте доступ команды и подключайте свои приложения через HTTP API.

Проект развивается в статусе **ранней беты**. Интерфейс и документация — на русском.
Первая модель размещения: отдельная установка для каждой команды.

[Документация](docs/index.md) · [Возможности](docs/guide/features.md) ·
[HTTP API](docs/reference/http.md) · [Участие в проекте](CONTRIBUTING.md)

## Возможности

- **Модель данных:** коллекции, типы полей, связи M:1 / 1:M / M:N,
  формы, подписи записей и поиск.
- **Работа с записями:** таблицы, вложенные фильтры, сохранённые виды,
  редактор в боковой панели, пакетные действия и история изменений.
- **Совместная работа:** комментарии к записям, участники страниц и карточек,
  проверка конфликтов при сохранении изменённых полей.
- **Доступ команды:** политики и права на действия, поля и строки,
  отдельные права на настройки и ограниченное делегирование политик.
- **Авторизация:** приглашения по ссылке без обязательной почтовой доставки,
  пароль, passkey, SSO/OIDC и управление сессиями.
- **Файлы:** библиотека и поля файлов с S3-совместимым хранилищем,
  включая Yandex Object Storage.
- **Интеграции:** сервисные аккаунты, ключи, GitLab CI federation
  и OAuth/OIDC provider для подключаемых приложений.
- **Расширения:** Kit для серверных обработчиков, собственных коллекций,
  миграций, настроек, страниц и редакторов полей.
- **SDK:** генерация типов через `asm connect`, вход через админку,
  fluent-запросы и типизированные методы плагинов без специального компилятора.
- **Опциональный ассистент:** потоковый чат, инструменты с правами пользователя
  и OpenAI-совместимый провайдер. [Личные подключения Google Drive и Sheets](docs/features/google-workspace.md):
  чтение по запросу и изменения после подтверждения пользователя.

Границы каждой функции описаны в [карте возможностей](docs/guide/features.md).
Workspaces группируют коллекции; они не разделяют данные разных компаний.
Блокировки полей, доставка правок в реальном времени, публичный MCP endpoint
и установка расширений из интерфейса пока не поддерживаются.

## Начать работу

Нужны **Node.js 22+, pnpm 11.13.1 и Docker Compose**. Из корня репозитория:

```sh
pnpm install --frozen-lockfile
pnpm db:up
```

Создайте `apps/core/.env` из [шаблона](apps/core/.env.example) и задайте случайный
`ASMBLYR_SETUP_TOKEN` длиной не менее 32 символов. Затем:

```sh
pnpm db:migrate
pnpm dev
```

Откройте [localhost:3000/setup](http://localhost:3000/setup), чтобы создать первого
администратора. Подробнее — [первый запуск](docs/guide/getting-started.md).
Для Docker есть единый образ с UI и Core API, собранными из исходников репозитория.
PostgreSQL и S3 подключаются отдельно: [установка и настройка](deploy/README.md).
Проверенные сборки `main` публикуются в `ghcr.io/asmblyr/collaborative:edge`;
для установки закрепляйте образ по digest.
SDK, CLI, Kit и общие контракты доступны в npm как `0.1.0-beta.1` под тегом
`beta`: [установка и подключение](docs/reference/packages.md). Docker-сборка
не зависит от предварительной публикации этих пакетов.

## Устройство проекта

| Каталог                            | Назначение                                         |
| ---------------------------------- | -------------------------------------------------- |
| `apps/core`                        | HTTP API, авторизация и PostgreSQL; Fastify и Knex |
| `apps/ui`                          | Админка; Next.js, React и shadcn                   |
| `packages/contracts`               | Общие публичные типы                               |
| `packages/sdk`                     | TypeScript HTTP-клиент                             |
| `packages/cli`                     | Подключение SDK и генерация типов                  |
| `packages/kit`                     | API и сборщик расширений                           |
| `packages/plugin-comments`         | Встроенный модуль комментариев к записям           |
| `packages/plugin-google-workspace` | Опциональные инструменты Google Drive и Sheets     |
| `examples`                         | Опциональные примеры расширений и интеграций       |
| `deploy`                           | Универсальные шаблоны Docker-установки             |
| `docs`                             | Пользовательские руководства и контракты           |
| `.agents`                          | Подробные инструкции для работы агентов с кодом    |

## Развитие и участие

Текущий фокус — устойчивость беты, совместимость SDK/Kit, документация и удобство
основных сценариев работы с данными. Новые возможности обсуждаются в
[Issues](https://github.com/Asmblyr/Collaborative/issues); сроки и состав следующих
релизов пока не закреплены.

Нашли ошибку или хотите предложить изменение? Начните с
[руководства для участников](CONTRIBUTING.md). Оно описывает запуск проверок,
правила изменений и подготовку pull request.
О вопросах безопасности читайте в [SECURITY.md](SECURITY.md).
