# Редактор условий и расширений — проверка согласованности UI

Дата: 2026-10-03. Проверка после замечаний пользователя о размере контролов, их выравнивании и расположении настроек расширений.

## Источники и состояние

- Пользователь попросил соблюдать действующий UI и использовать shadcn. Ранее сгенерированный концепт с контролами 48 px больше не является эталоном размеров. Предыдущий отчёт сохранён в `artifacts/row-permissions-design-qa-before-consistency.md`.
- Эталон действующей формы: `artifacts/ui-consistency-native-reference.png`, штатный редактор политики.
- Реализация: `http://localhost:3000/system-settings/policies`, политика → коллекция → чтение. Снимок: `artifacts/ui-consistency-conditions.png`.
- Совместное полное сравнение: `artifacts/ui-consistency-comparison.png`. Штатный редактор слева, редактор условий справа. Детальное сравнение: `artifacts/ui-consistency-detail.png`. Сравниваются типографика, плотность и токены компонентов; содержание и ширина двух редакторов различаются намеренно.
- Оба исходных desktop-снимка 1280 × 900. Совместный полный снимок 2560 × 900; детальные вырезки сохраняют исходный масштаб.
- Тёмная тема; условия «Автор = Текущий пользователь» и «Статус = Опубликовано». Использованы временная локальная политика без назначенных пользователей и тестовая коллекция.
- Мобильный viewport запрошен 390 × 844; наблюдаемый CSS viewport 391 × 844, ширина без полосы прокрутки 376 px. Снимок IAB 376 × 814: `artifacts/ui-consistency-conditions-mobile.png`. Меню: `artifacts/ui-consistency-parameters-mobile.png`.
- Расширения: `artifacts/ui-consistency-plugins-list.png`, `artifacts/ui-consistency-plugin-editor.png`, `artifacts/ui-consistency-plugin-editor-mobile.png`.

## Исправления и наблюдаемая геометрия

- Удалены отдельный увеличенный размер редактора условий, крупная типографика и дополнительные отступы. Используется общий native EditorDialog с заголовком 20 px и стандартными отступами.
- Поле и значение используют один небольшой компонент на основе существующего shadcn Button; оператор использует существующий shadcn Select в размере sm. Все три элемента имеют высоту 27,995 CSS px и шрифт 14 px. Их верхняя координата в первой desktop-строке одинаковая: 226,458 CSS px. Обёртки используют flex, чтобы inline-flex не добавлял смещение относительно текстовой базовой линии.
- Одинаковые рамки, скругления, правые отступы и иконки стрелок. Используются токены input/background/foreground и штатное фокусное состояние. Отдельное декоративное выделение открытого значения убрано.
- Параметры отображаются компактными однострочными пунктами. Пояснение, технический путь и тип сохранены в title. Поиск по названию, описанию и пути сохранён. Меню шириной до 20rem, внутренний отступ 8 px.
- На узком экране редактор больше не выступает за левую границу. Причина: 100vw учитывал полосу прокрутки; доступная ширина fixed-окна рассчитывается через 100%. После исправления левый отступ 8,008 CSS px, ширина 359,831 CSS px при доступной ширине 376 px. Правые границы и нижние действия доступны.
- На странице расширений остаётся список плагинов. Клик строки или доступной с клавиатуры кнопки открывает общий правый редактор. Плагины без настроек показывают описание состояния и разрешённые возможности.
- Существующая форма настройки плагина подключена к общей защите несохранённых изменений и состоянию занятости. Увеличенных контролов или встроенного редактора на странице списка нет.

## Проверенные взаимодействия

- Поиск поля по техническому имени и параметра по user.id; выбор текущего пользователя закрывает меню и возвращает фокус.
- Поле, значение и оператор открываются; Escape закрывает меню, сохраняя окно редактора.
- Мобильная компоновка условий, открытое меню параметров, доступность нижних кнопок; настройки плагина на обеих ширинах.
- Открытие расширения с настройками и без них; клавиатурное открытие; закрытие с возвращением фокуса.
- Несохранённое изменение параметра плагина вызывает подтверждение; продолжение редактирования, сброс черновика и закрытие проверены. Значения настроек в API при этой проверке не менялись.
- Новых ошибок в журнале браузера после исправлений не обнаружено.
- Временная локальная коллекция, политика, пользователь и файл с тестовой сессией удалены после проверки. Тестовые cookies удалены, размер viewport сброшен.
- Проверка типов, линтер, сборка и форматирование проходят. UI-тесты: 80 passed, 0 failed, 0 skipped. Логи: `artifacts/ui-consistency-*.log`. Проверка документации ранее прошла после описания нового списка расширений.
